# Запуск ноутбуков

Создайте окружение и установите зависимости проекта из его корневой папки:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

В VS Code откройте файл `.ipynb` и выберите ядро Python из `.venv` через **Select Kernel**. Также можно запустить JupyterLab из корня проекта:

```bash
.venv/bin/python -m jupyter lab
```

Для дополнительных Python-библиотек выполните в ячейке `%pip install имя_пакета`: пакет установится в окружение выбранного ядра. При необходимости перезапустите ядро. Для других языков нужны отдельные установленные ядра Jupyter; наличие ядра и необходимых библиотек не исправляет ошибки в самом коде.
